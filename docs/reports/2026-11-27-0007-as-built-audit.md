# 0007 A2A runtime chain — as-built offset audit

## 范围与方法

- 文档：`docs/architecture/0007-a2a-runtime-chain.md`（4171 行，target contract；
  2026-11-27 已加 §0.1 as-built note）。
- 实现基线：`f51d9f3c7`（F043 merged；live 3005/3014 同版）与 live DB 的
  `sqlite_master` / `pragma table_info`。
- 判定：
  - **target-only**：文档写成 v1 设计，当前代码没有对应组件/接口；
  - **ownership**：行为存在，但 owner/调用位置不同；
  - **undocumented**：代码有、文档没有；
  - **DDL/API**：表列、约束或方法签名不一致。

## 结论

0007 整体仍是一份有价值的 target contract，但**不是 as-built 文档**。核心偏移集中在：

1. route 层（`AgentRouter`/`routeAgents`/`routeParallel`/`routeSerial`/`priorResponses`）
   在当前代码中不存在；实际调度在 `QueueProcessor.processEntry`。
2. Phase B（R/turn/credential/draft/retire）在 `QueueProcessor`，不在 `runAgentTurn`。
3. T2 在 `RunAgentTurn.dispatch`，不在 route/`RouteResponseCommitter` 外层。
4. `runAgentTurn` 是 `RunAgentTurn.dispatch(prepared): Promise<void>`，不是 async generator /
   `AgentTurnResult`。
5. 组件 API（QueueProcessor deps/methods、InvocationRecordStore methods）与文档接口不一致。
6. 数据模型有两处明确差异（`response_drafts.rich_blocks_json`；`invocation_records` 唯一约束）。
7. F031/F043 的新行为（rich block producer、并发 fan-out、trigger snapshot、auto-delivery
   拒绝）没有进入 §3.5.1/§3.8/§6/§9。
8. `MessageDispatchSummary` 读模型在文档中声明由 F018 拥有，但当前代码没有实现。

## 已核对且未发现偏移的部分

- `invocation_queue` 的 queued/claimed、claim CAS、`queue_admissions` receipt、per-kind cap 5、
  priority/position；`targets_json` 空数组作为 terminal/retry anchor。
- Phase A 单事务（parent + attempts starting）、`tracker.startAll` 的 per-agent 槽位、
  Phase B 每 target 的 R/turn/credential/draft/retire。
- T1 `TurnExecutionLifecycle.invokeTerminal`（child terminal + attempt projection +
  credential + ack）、T3 `aggregateParent`（collector + `applyTerminalAggregate`）、
  T4 `ResponseRecoveryService`。
- `invocation_attempts` / `invocation_credentials` / `agent_read_state` / `workers` /
  `worker_bindings` 的 DDL 与状态集合（C5/C6）。
- `post_message`/`cross_post_message`/`multi_mention`/`thread_context` 四个 A2A tool 的
  input/output、targets 上限、message+queue+parent 账本形态、multi-mention callback 表。
- `messages` 物理映射、`response_drafts` 的 100ms/4KB flush、`listResponsePending` /
  `clearResponsePending`、session/delivery cursor 的正常路径。
